# Development plans

- `INBOX.md` — quick ideas, bugs, observations, possible fixes, questions, and things noticed while using Sporely.
- `active/` — scoped development plans currently being worked on or not yet completed.
- `completed/` — finished plans retained for design and history context.

Plans describe intent and decisions. Git history is the source of truth for what was actually implemented.

This directory is not the home for repository instructions, current
architecture, operational runbooks, or user documentation. Those belong in
`AGENTS.md`, the relevant architecture/contract document, or the appropriate
permanent documentation location.

## Workflow

1. Capture rough observations in `INBOX.md`.
2. Promote related inbox items into a named active plan.
3. Develop the plan with GPT.
4. Record stages, boundaries, decisions, acceptance criteria, and agent handoff context.
5. Move the plan to `completed/` when the corresponding work is finished.

Stage numbers are local to each named plan. Do not use them as repository-global identifiers.
