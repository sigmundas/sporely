# ADR 0001: Global taxonomy authority

- Status: Accepted
- Date: 2026-07-23

## Context

Regional sources disagree about accepted names, while Sporely needs stable
international presentation and strong Norwegian and Swedish search.

## Decision

Version-pinned Catalogue of Life Extended Release controls the one global
accepted scientific presentation. Country never selects a different scientific
authority. NorTaxa and Artportalen names remain searchable usages/aliases and
their disagreements are preserved. iNaturalist is enrichment only. Every source
release is pinned and recorded.

## Consequences

Local names and assessments remain available without replacing the global
canonical name. Reconciliation must retain conflicting evidence.

## Rejected alternatives

- Country-specific accepted backbones: inconsistent identity and display.
- NorTaxa or Artportalen as global authority: regional coverage.
- iNaturalist as authority: enrichment semantics and mutable community data.
