## 4. Import + activation — PRODUCTION WRITE (separate explicit approval required)
```bash
docker run --rm --env-file $ENV -v "$SQLD:/payload:ro" postgres:17 \
  sh -c 'psql "$DATABASE_URL" -X --file=/payload/tax-2026.10.23-11-import.sql'
echo "exit $?"
```
One transaction. The SQL sets lock_timeout 10 s and statement_timeout 30 min itself, loads and validates
without client-blocking locks, then the cutover: activation advisory lock → ACCESS EXCLUSIVE on
`taxonomy_v2_releases` → write locks on the reference holders → protected-state snapshot → activate →
selected-concept check → COMMIT. Expected: exit 0; ~6 s total (rehearsal 6.2 s).
Failure (non-zero exit, e.g. lock timeout or a selected concept absent from -11): the transaction rolls
back completely, 10.07 stays active; rerun step 3, fix the cause, then the same SQL can be rerun.
