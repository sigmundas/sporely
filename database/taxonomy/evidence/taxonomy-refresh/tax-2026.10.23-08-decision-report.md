entry per Sporely ID in a closed exchange. When the owner approves **both**
members of a pair (`name_record_follow` in the COL id-continuity decision file),
the compiler gives each ID, in that release only, the current COL record that
carries its original IF record. No registry key is rebound, nothing is allocated,

- 0 observations. Recommended: a reviewed supersession 152153 → 167358 (both sources agree).
